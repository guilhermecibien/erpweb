# Pendências de modernização

Este arquivo lista o que falta atualizar no ERP com foco em **ambiente local**, sem preocupação com VPS/produção por enquanto. O objetivo aqui é tirar o sistema do estado legado: stack, dependências e frontend.

## Já modernizado

- [x] PHP 8.3 como runtime alvo, pipeline de CI atualizado para essa versão.
- [x] Dependências genéricas e bibliotecas fiscais compatibilizadas com PHP 8.3.
- [x] Laravel migrado de 8.x para 9.x, depois 9→10, 10→11 e 11→12 (ver detalhes em "Atualização da stack"). Versão suportada mais recente atingida — próximos saltos de major só quando o Laravel lançar uma nova.
- [x] `laravelcollective/html` (abandonado, sem versão compatível com Laravel 11+) substituído por um shim local próprio em `app/Support/FormHtml/` — ver detalhes em "Atualização da stack".
- [x] Laravel Mix/Webpack substituído por Vite.
- [x] Dependências principais do build frontend atualizadas, sem `npm audit` pendente na última checagem.
- [x] Corrigido carregamento de views do Superadmin e recuperado controlador do carrossel do e-commerce.

> A interface ainda usa Blade, AdminLTE e jQuery legados — o Vite modernizou o build, não a interface em si.
